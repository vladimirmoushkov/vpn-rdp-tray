# Third-party notices

The Windows installer includes Microsoft’s .NET and Windows Desktop runtime files for a self-contained deployment. The build copies the license and notice files from the exact runtime packs used. See those installed text files for the applicable terms. [Microsoft .NET license information](https://github.com/dotnet/core/blob/main/license-information.md) · [Windows distribution terms](https://github.com/dotnet/core/blob/main/license-information-windows.md)

Inno Setup builds the installer. Its license terms and acknowledgments are maintained by the upstream project. [Inno Setup license](https://jrsoftware.org/files/is/license.txt)

OpenVPN Community is a separately installed dependency. The installer for this application carries the tray client and runtime. Settings can download OpenVPN’s official MSI during the explicit installation step. [OpenVPN distribution and signatures](https://community.openvpn.net/Downloads) · [OpenVPN license](https://github.com/OpenVPN/openvpn/blob/v2.7.9/COPYING)

Remote Desktop Connection, the Remote Desktop ActiveX control, and Windows DPAPI are Windows components used through the installed operating system. [Remote Desktop ActiveX control](https://learn.microsoft.com/en-us/windows/win32/termserv/remote-desktop-activex-control)
